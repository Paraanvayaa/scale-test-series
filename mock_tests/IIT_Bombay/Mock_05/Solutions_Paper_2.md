### Questions 45 to 50 (Mathematics Numerical Values)
- **Q45**: Using King's property $x \to \pi/2 - x$:
  $$I = \int_0^{\pi/2} \frac{\cos x}{1 + \cos x + \sin x}\,dx = \int_0^{\pi/2} \frac{\sin x}{1 + \cos x + \sin x}\,dx$$
  Adding:
  $$2I = \int_0^{\pi/2} \frac{\cos x + \sin x}{1 + \cos x + \sin x}\,dx = \int_0^{\pi/2} \left[1 - \frac{1}{1 + \cos x + \sin x}\right]dx = \frac{\pi}{2} - \int_0^{\pi/2} \frac{dx}{1 + \cos x + \sin x}$$
  Using $t = \tan(x/2)$: $\int_0^{\pi/2} \frac{dx}{1 + \cos x + \sin x} = \int_0^1 \frac{2\,dt}{2 + 2t} = [\ln(1 + t)]_0^1 = \ln 2$.
  Thus $2I = \frac{\pi}{2} - \ln 2 \implies I = \frac{\pi}{4} - \frac{1}{2}\ln 2 = 0.7854 - 0.3466 = 0.44$. **Ans: 0.44**
